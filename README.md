# Development-of-Interactive-Cyber-Threat-Visualization-Dashboard
**Group:** Group 1 | **Company:** Infosys Internship Project

## Project Overview
This project aims to create a real-time, interactive dashboard for cybersecurity analysts. It visualizes simulated security incident data to identify attack patterns, geographical hotspots, and temporal trends.

## Repository Structure
- `Model_Research.md`: Analysis of threat detection models.
- `data_generator.py`: Python script to generate the dummy dataset.
- `cyber_threat_data.csv`: The generated dataset with 350+ records.
- `queries.sql`: SQL scripts for data analysis.

## Tech Stack
- **Language:** Python
- **Data Analysis:** Pandas, SQL
- **Visualization:** Plotly/Dash (Coming soon)
